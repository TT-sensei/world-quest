# WORLD QUEST

世界の国や地域、文化に出会うための、小学生向け学習Webアプリです。

「国名を覚える」だけで終わらず、国旗・地域・大陸・場所・世界遺産・文化・食・建物・自然・シンボルなど、いろいろな入口から国を知ることをねらいとしています。

## 国図鑑

「国図鑑」では、収録されている国を一覧から探すことができます。

国名を検索したり、地域で絞り込んだりしながら、各国の資料をアコーディオン形式で見ることができます。

国図鑑はクイズとは別に、気になった国を調べるための入口として利用できます。

収録されていない国については、図鑑上で「まだ図鑑にはありません」と表示します。

## 対象

小学校高学年を想定しています。

タブレットでの利用を中心に、問題・選択肢・結果が見やすく、操作しやすいUIを目指しています。

## 特徴

- ブラウザだけで動作
- GitHub Pagesで公開可能
- サーバー・データベース不要
- APIキー不要
- 学習記録は端末のlocalStorageを利用
- ナビキャラクターによるフィードバック
- アチーブメント・バッジ機能
- 国旗や写真など、実際の資料を使った出題
- 地図や地球の画像を使い、地理的なイメージを持ちやすくする構成
- 国図鑑で国を検索・地域別に絞り込み可能

## 技術構成

HTML / CSS / JavaScriptによる静的Webアプリです。

主なファイル構成：

- `index.html` — 画面構成
- `styles.css` — デザイン・レスポンシブ対応
- `app.js` — クイズの進行、判定、記録など
- `data/countries/*.js` — 国ごとの国・クイズデータ
- `data/achievements.js` — アチーブメント・バッジ定義
- `assets/flags/` — 国旗画像
- `assets/` — 地図・背景などの素材

国データは国ごとに分割して管理しています。

例：

```
data/countries/
├── jp.js
├── us.js
├── cn.js
├── kr.js
├── au.js
├── br.js
├── cl.js
└── ...
```

新しい国を追加するときは、原則として国ごとのJSファイルを追加し、`index.html`から読み込みます。

## 国データ・画像について

国データには、国名・コード・地域・大陸・首都・国旗などの基本情報と、各分野の資料を登録しています。

写真・資料画像には、主にWikimedia Commonsなど、利用条件を確認できる公開資料を使用しています。

資料を探すときは、1つの検索結果だけで決めず、国名・英語名・都市名・文化・伝統・祭り・食・世界遺産・建築・自然・代表的な場所など、複数の切り口から探します。

小学生が見て内容を理解しやすいこと、国との関連が明確であること、写真として見やすいこと、資料として正確であること、利用条件を確認できることを重視します。

資料が見つからない場合も、すぐに空欄にはせず、複数の候補を調べたうえで、品質・正確性・権利条件を満たすものが見つからない場合に限って空欄とします。

## 収録国を増やす方針

国の数を増やすことだけを目的にはしません。

小学生にとって身近な国、日本とのつながりを感じやすい国、学校で学ぶ内容と関連する国、特徴的な文化や自然を知ることができる国などを優先しながら、地域的なバランスも考えて追加していきます。

特定の地域だけに偏らないよう、アジア・ヨーロッパ・アフリカ・北アメリカ・南アメリカ・オセアニアを少しずつ広げていきます。

ただし、地域の数合わせのために資料の質を下げることはしません。

## データ追加時の基本方針

新しい国を追加するときは、次の点を確認します。

1. 国名・国コード・地域・大陸・首都・国旗を正確に登録する。
2. 国旗画像が正しく表示されることを確認する。
3. 各分野について、子どもが見て「これは何だろう」と興味を持てる資料を探す。
4. Wikimedia Commonsなどで複数の候補を比較する。
5. 写真の内容、国との関連、画質、子どもへの分かりやすさを確認する。
6. ライセンスとクレジットを確認する。
7. 空欄は最後の選択肢とし、十分に探しても適切な資料が見つからない場合だけ使用する。
8. 追加後はクイズだけでなく、国図鑑の表示も確認する。

## データ・画像の権利について

国旗・写真・地図などの外部素材には、このリポジトリとは別に、それぞれの原作者・配布元が定めるライセンス・利用条件が適用されます。

Wikimedia Commonsの資料を使用する場合も、個別ファイルのライセンス・作者・出典を確認します。

ナビキャラクターは `TT-sensei/navi-character-` の素材を使用しています。

外部素材を利用する場合は、必ず元資料の利用条件を確認してください。

## ライセンス・利用について

このリポジトリのコードおよびTT-senseiオリジナルの教材・画像・キャラクター素材について、学校・家庭などでの非営利の学習利用を想定しています。

一方で、次の行為は許可していません。

- コードやオリジナル教材の商用利用
- オリジナル画像・キャラクター素材の商用利用
- 素材ファイルだけを取り出して再配布・販売すること
- このリポジトリの素材を利用した教材・サービスを、そのまま素材集として再配布すること

外部から取得している国旗・写真・地図などについては、それぞれの原作者・配布元が定める条件が優先されます。

## 教育的な考え方

WORLD QUESTでは、クイズそのものを目的にするのではなく、

「答えを知る」
↓
「ちょっと気になる」
↓
「もう少し世界を知る」

という流れを大切にしています。

問題を解いたあとに表示される写真や短い説明をきっかけに、国・地域・文化への興味を広げることを目指しています。

## 開発方針

TT-senseiの学習アプリとして、次の方針で開発しています。

- 無料で使える構成を基本とする
- APIキーや有料APIに依存しない
- 不要な外部サービスを増やさない
- タブレットでの操作性を優先する
- 子どもが迷わず操作できる画面にする
- 学習内容が主役になるよう、過度な装飾やゲーム要素を避ける
- ナビキャラクターは学習を邪魔しない範囲で活用する
- 国を知るきっかけになる資料の質を優先する
