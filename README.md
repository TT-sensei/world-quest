# WORLD QUEST

クイズを解きながら、世界の国や地域、文化に出会う小学生向けの学習Webアプリです。

「国名を覚える」だけで終わらず、国旗・地域・大陸・世界遺産・文化・食・自然など、いろいろな入口から国を知ることをねらいとしています。

## アプリ

**WORLD QUEST**
https://tt-sensei.github.io/world-quest/

GitHubリポジトリ：
https://github.com/TT-sensei/world-quest

## 現在の内容

現在は15か国を収録しています。

- 日本
- アメリカ
- イギリス
- 南アフリカ
- ブラジル

各国について、次のようなクイズを出題します。

- 国旗
- 地域
- 大陸
- 有名な場所
- 世界遺産
- 文化
- 食
- 建物・施設
- 自然
- シンボル・特色

問題は出題順をシャッフルし、4択で回答します。正解・不正解のあとには、短い解説を表示します。

## 対象

小学校高学年を想定しています。

タブレットでの利用を中心に、問題・選択肢・結果が見やすく、操作しやすいUIを目指しています。

## 特徴

- ブラウザだけで動作
- GitHub Pagesで公開可能
- サーバー・データベース不要
- APIキー不要
- 学習記録は端末のlocalStorageを利用
- 正解したことのある国を「知った国」として記録
- ナビキャラクターによるフィードバック
- 合計正解数と分野別の正解数に応じて増える70個のアチーブメントバッジ
- バッジは端末のlocalStorageに保存し、集めた数を表示
- 国旗や写真など、実際の資料を使った出題
- 地図や地球の画像を使い、地理的なイメージを持ちやすくする構成

## 技術構成

HTML / CSS / JavaScriptによる静的Webアプリです。

主なファイル構成：

- `index.html` — 画面構成
- `styles.css` — デザイン・レスポンシブ対応
- `data/countries.js` — 国・クイズデータ
- `app.js` — クイズの進行、判定、記録など
- `assets/flags/` — 国旗画像
- `data/achievements.js` — アチーブメント・バッジ定義

外部サーバーやバックエンドは使用していません。

## データ・画像について

国旗には、country-flagsプロジェクトのSVGを使用しています。

写真・地図などの資料画像には、主にWikimedia Commonsの公開資料を使用しています。表示用には軽量な画像を使用し、可能な場合は元資料へのリンクを保持しています。

ナビキャラクターは [TT-sensei/navi-character-](https://github.com/TT-sensei/navi-character-) の素材を使用しています。

それぞれの画像・素材について、権利関係や利用条件は必ず元の配布元を確認してください。

## ライセンス・利用について

このリポジトリのコードおよびTT-senseiオリジナルの教材・画像・キャラクター素材について、学校・家庭などでの非営利の学習利用を想定しています。

一方で、次の行為は許可していません。

- コードやオリジナル教材の商用利用
- オリジナル画像・キャラクター素材の商用利用
- 素材ファイルだけを取り出して再配布・販売すること
- このリポジトリの素材を利用した教材・サービスを、そのまま素材集として再配布すること

外部から取得している国旗・写真・地図などについては、このリポジトリのライセンスとは別に、それぞれの原作者・配布元が定めるライセンス・利用条件が適用されます。

外部素材を利用する場合は、元資料のライセンスを確認してください。

## 教育的な考え方

WORLD QUESTでは、クイズそのものを目的にするのではなく、「答えを知る → ちょっと気になる → もう少し世界を知る」という流れを大切にしています。

問題を解いたあとに表示される写真や短い説明をきっかけに、国・地域・文化への興味を広げることを目指しています。

今後は、国を増やしたり、問題の種類を増やしたりしながら、世界を知る入口として育てていく予定です。アチーブメントも、収録国や問題数の増加に合わせて拡張できます。

## 開発方針

TT-senseiの学習アプリとして、次の方針で開発しています。

- 無料で使える構成を基本とする
- APIキーや有料APIに依存しない
- 不要な外部サービスを増やさない
- タブレットでの操作性を優先する
- 子どもが迷わず操作できる画面にする
- 学習内容が主役になるよう、過度な装飾やゲーム要素を避ける
- ナビキャラクターは学習を邪魔しない範囲で活用する
